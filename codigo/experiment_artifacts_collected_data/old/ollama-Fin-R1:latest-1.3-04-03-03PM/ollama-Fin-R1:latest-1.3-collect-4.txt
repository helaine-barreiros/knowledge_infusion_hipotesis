### Final Diagram Explanation:
The use case diagram above outlines the interactions in a personal financial management system. Here's a breakdown of each component and relationship:

1. **Use Cases**:
   - **UC01: Visualizar Lista de Transações**: The core activity where users view their transaction history.
   - **UC02: Filtrar Transações**: Sub-use case included within UC01, allowing filtering transactions by date, category, or value.
   - **UC03: Categorizar Transação Manualmente**: An extension of UC01, permitting manual re-categorization of existing transactions.
   - **UC04: Buscar Transações**: A search function integrated into the main viewing process (part of UC01).
   - **UC05: Ver Detalhes da Transação**: Allows users to view detailed information on selected transactions.
   - **UC06: Exportar Transações**: Exports transaction data in formats like CSV or PDF.
   - **UC07: Receber Categorização Automática**: Automated categorization linked to UC01, enhancing efficiency without manual input.

2. **Relationships**:
   - **Inclusion (UC02)**: Filtros are a part of the transaction list viewing process (one-way relationship).
   - **Extension (UC03)**: Categorizing manually is an optional action after viewing transactions.
   - **Integration (UC04 and UC05)**: Searching and viewing details are embedded within the main transaction viewing flow.
   - **Grouping (UC06)**: Exporting transactions is tied to the same context as viewing them.
   - **Support from Bank (UC07)**: The system’s automated categorization depends on banking data, modeled via the `bank` actor.

3. **Actors**:
   - **user**: Represents the end-user of the financial management system.
   - **bank**: Represents the source of transactional data (e.g., the bank).

This structure ensures that all use cases and their dependencies are clearly defined, providing a comprehensive view of how transactions are managed within the system. The relationships reflect both sequential and optional actions, encompassing viewing, searching, categorizing manually or automatically, exporting, and managing transaction details.
