## Container Overview

The system architecture follows a microservices approach with clear separation of concerns between containers. The architecture can be divided into several logical groupings:

### User-Facing Applications

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **Web Application** | Angular | Browser-based application | Provides the primary user interface for customers and advisors to interact with the system via web browsers |
| **Mobile Application** | Ionic Angular | Mobile application | Offers a mobile-optimized experience for users on iOS and Android devices |

### API Layer

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **API Gateway** | Spring Cloud Gateway | Central entry point for API requests | Routes client requests to appropriate backend services, handles authentication verification, rate limiting, and acts as a facade for the microservices |

### Core Backend Services

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **Identity Service** | Spring Boot, Spring Security | Authentication and authorization service | Manages user authentication, authorization, user profiles, and security concerns |
| **Financial Aggregation Service** | Spring Boot | Financial data aggregation service | Collects, consolidates, and normalizes financial data from multiple institutions |
| **Transaction Service** | Spring Boot | Transaction management service | Handles the recording, categorization, and analysis of financial transactions |
| **Goal Service** | Spring Boot | Financial goal management service | Manages the creation, tracking, and analysis of financial goals |
| **Notification Service** | Spring Boot | Alert and notification service | Generates and delivers notifications and alerts based on system events |
| **Advisor Portal Service** | Spring Boot | Advisor collaboration service | Manages the sharing of financial data between customers and advisors |
| **Finance Data Collector** | Spring Boot | External API integration service | Handles connections to external financial APIs and data collection |

### AI and Machine Learning Services

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **AI Inference Service** | Python, FastAPI | Real-time inference service | Provides AI-powered insights and recommendations based on trained models |
| **AI Training Service** | Python, TensorFlow/PyTorch | Model training service | Trains and updates AI models using financial data |
| **NLP Service** | Python, Hugging Face Transformers | Natural language processing service | Processes conversational interactions for the chatbot interface |

### Data Storage

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **Operational Database** | PostgreSQL | Relational database | Stores transactional data, user information, and operational records |
| **Analytical Database** | MongoDB | Document database | Stores processed financial data optimized for analytics and AI consumption |
| **Distributed Cache** | Redis | In-memory data store | Caches frequently accessed data and manages session information |

### Messaging

| Container | Technology | Description | Responsibility |
|-----------|------------|-------------|----------------|
| **Event Bus** | RabbitMQ | Message broker | Facilitates asynchronous communication between services using publish/subscribe pattern |

## Communication Patterns

The system uses two primary patterns of communication:

### Synchronous Communication
- **Protocol**: REST over HTTPS
- **Format**: JSON
- **Authentication**: JWT tokens
- **Primary Use**: Direct user interactions and immediate data needs

### Asynchronous Communication
- **Protocol**: AMQP via RabbitMQ
- **Message Format**: JSON
- **Primary Use**: Event notifications, data processing triggers, and background operations

## Data Flow

The system's primary data flows include:

1. **User Interaction Flow**:
   - Users interact with Web or Mobile applications
   - Applications communicate with backend services via the API Gateway
   - Services process requests and return responses

2. **Financial Data Collection Flow**:
   - Finance Data Collector retrieves data from external financial APIs
   - Collected data is published to the Event Bus
   - Financial Aggregation Service processes and normalizes the data
   - Processed data is stored in the Operational and Analytical Databases

3. **AI Insight Generation Flow**:
   - AI Training Service periodically trains models on data from the Analytical Database
   - AI Inference Service uses trained models to generate real-time insights
   - Insights are delivered to users through the Web and Mobile applications

4. **Notification Flow**:
   - Various services publish events to the Event Bus
   - Notification Service subscribes to relevant events
   - Notifications are generated and delivered to users

### Integration and Messaging
- **Message Broker**: RabbitMQ
- **External API Integration**: REST, OAuth2, API Keys

## Security Approach

The system implements a multi-layered security approach:

1. **Authentication**: 
   - JWT-based authentication via the Identity Service
   - OAuth2 integration for third-party authentication

2. **Authorization**:
   - Role-based access control
   - Resource-level permissions

3. **Data Protection**:
   - TLS for data in transit
   - Encryption for sensitive data at rest
   - Secure credential management for external API access

## External System Integrations

The system integrates with several external systems:

1. **Banking APIs**: Access to banking transactions and account information
2. **Investment APIs**: Access to investment portfolios and market data
3. **Credit Scoring Service**: Access to credit scores and related information
4. **Financial News Service**: Access to financial news and market updates
5. **Financial Education Content**: Access to educational materials
