- **System**: Contains core use cases like viewing financial dashboards, managing analysis parameters, generating personalized recommendations, and more. It also includes system administrators who manage the AI's settings.
- **Client**: Represents users (clients) with various needs such as viewing predictions, receiving alerts, etc.
- **Financial Advisor**: Includes activities related to mentoring sessions, client intervention alerts, and predictive analytics for clients.
- **System Administrator**: Manages analysis parameters, spending thresholds, and other system-wide configurations.
- **AI System**: The AI components generate financial insights, recommendations, transaction analyses, investment opportunities, news extraction, etc.

### Key Relationships:
1. **Client** interacts with the system through various use cases (e.g., viewing dashboards, receiving alerts).
2. **Financial Advisor** uses client data to schedule sessions and receive alerts.
3. **System Administrator** configures parameters for both the main system and AI components.
4. The **AI System** generates insights that are consumed by clients or advisors.
