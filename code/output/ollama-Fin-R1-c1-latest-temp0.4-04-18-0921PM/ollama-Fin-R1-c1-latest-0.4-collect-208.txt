- **Client Package**: Contains all use cases related to clients (CFRs). Each client can interact with multiple use cases.
- **Financial Advisor (FA) Package**: Includes FAFR-related use cases for advisors. Advisors view alerts and predictive analytics about their clients.
- **System Administrator (SA) Package**: Only one actor, SysAdmin, manages analysis parameters (SAFR001).
- **System Boundary**: Encloses all components within the system's scope.

### Key Relationships:
- Clients interact with most CFR use cases directly. For example, viewing financial insights or receiving recommendations.
- Advisors can view client-specific recommendations and alerts via FAFR-related use cases.
- SysAdmin manages AI parameters through SAFR001. No other actors are involved here as it's a system-level task.
