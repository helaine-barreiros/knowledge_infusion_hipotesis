**Description:**
- The system is divided into three main components: **User Interface (UI)**, **System Core (SC)**, and **AI Component (AC)**. Each component contains use cases relevant to their function.
  
- **Client**: Can view financial dashboards, receive alerts, make predictions, get recommendations, manage preferences, check spending limits, explore investments, access personalized dashboards, and manage advisor relationships.

- **System Administrator** manages analysis parameters for the AI system (SAFR001) and configures analysis parameters for client segments (FAFR004), which extends SAFR001.

- **Financial Advisor/Client**: Can configure params for segments via FAFR004, which is linked to SAFR001. This establishes a relationship where the advisor can adjust system settings based on segment-specific needs.
  
This structure ensures clarity in how actors interact with use cases across different subsystems and components of the AI-powered analysis & insights system.
