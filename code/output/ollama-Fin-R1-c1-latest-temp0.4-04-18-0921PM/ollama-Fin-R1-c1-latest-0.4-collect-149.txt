- **System Boundary**: The entire diagram is enclosed within a rectangle labeled "System" to represent the AI-Powered Analysis & Insights System.
- **Use Cases**:
  - `CFR001` (Client): View Financial Insights Dashboard.
  - `SAFR001` (SysAdmin): Manage Analysis Parameters for compliance and accuracy.
  - `FAFR004`: Configure analysis parameters specifically for client segments by financial advisors.
  - `SFR002`: Deliver personalized recommendations to users via the system.
  - `SFR003`: Request financial predictions from the AI component (e.g., market trends).
  - `SFR005`: Request spending limit alerts when user activity exceeds thresholds.
  - `SFR006`: Request investment opportunity analyses based on risk profiles and goals.
  - `AIFR005`: Generate investment opportunities aligned with client’s ESG preferences (AI component).
- **Actors**:
  - **Client**: Interacts directly with the system to view dashboards, receive recommendations/alerts.
  - **SysAdmin**: Manages analysis parameters for compliance and accuracy.
  - **FinancialAdvisor**: Configures AI settings for clients and manages alerts/interactions.
  
### Key Relationships:
- Clients interact with `CFR001` (viewing dashboard) directly. 
- SysAdmin uses `SAFR001` to adjust system-wide parameters.
- Financial Advisors use both `FAFR004` (configuring AI for segments) and `SFR013` (managing client alerts).
- The System itself drives interactions with other components like delivering recommendations (`SFR002`), requesting data from the AI (`SFR003`, etc.), generating dashboards/alerts (`SFR012`, `SFR013`).
