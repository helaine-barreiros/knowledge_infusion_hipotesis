- **Client**: Represents the end-users, including clients and financial advisors. They interact with use cases like viewing dashboards, receiving recommendations, etc.
- **System Administrator (SysAdmin)**: Manages system parameters such as analysis settings and compliance rules via `SAFR002`.
- **Financial Advisor (FA)**: Engages in client mentoring sessions (`FAFR005`) based on AI-generated insights. Also receives predictive alerts (`AIFR008`).
- **System Services**: Handles generating dashboards, managing alerts, providing financial analytics.
- **AI Component**: Responsible for core functionalities like predictions, recommendations, anomaly detection, etc.

### Key Relationships:
1. **Client** interacts with most use cases directly (e.g., viewing dashboards, receiving recommendations).
2. **SysAdmin** manages system-level parameters affecting the AI’s behavior (`SAFR002`).
3. **FA** uses predictive insights to schedule sessions and make client-specific decisions.
4. The **AI Component** serves as a central processing unit generating all data-driven outputs.
