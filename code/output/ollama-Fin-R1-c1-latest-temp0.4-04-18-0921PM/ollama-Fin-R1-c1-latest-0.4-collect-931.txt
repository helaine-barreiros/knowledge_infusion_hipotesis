**Key Relationships and Grouping Explanation:**
- **System Actors:** The system is represented by a rectangle containing use cases related to its functionalities. These include managing analysis parameters, delivering alerts, generating dashboards, etc.
- **Client Use Cases:** Clients can view various financial insights (CFR001), receive personalized recommendations (CFR004), manage preferences (CFR005), and more.
- **Financial Advisor Use Cases:** Advisors can configure segment-specific analysis parameters (FAFR004) and access predictive analytics for clients (FAFR003).
- **System Administrator Use Cases:** Admins handle system-level tasks like managing parameters, maintaining historical records, and collecting user feedback via CFR011.
- **AI Component:** The AI handles core functionalities such as generating predictions, personalized recommendations, spending limit alerts, investment opportunities, etc. These are grouped under "AIFR."
- **System (SFR):** This includes use cases like generating dashboards (SFR012) and delivering timely alerts (SFR013).
- **Client to AI:** Relationships between clients and the system or AI components for receiving recommendations, predictions, etc.
- **Feedback Loop:** A client can provide feedback on received insights/recommendations via CFR011.

This structure ensures clarity in how different actors interact with various use cases within the system. Each rectangle groups related entities (actors/usecases) to maintain readability and logical flow. Relationships are established through arrows indicating directionality of interaction.
**Note:** The "User" category includes all clients, financial advisors, and admins as per requirement CFR011, but specific interactions are categorized under their respective roles/actors.
