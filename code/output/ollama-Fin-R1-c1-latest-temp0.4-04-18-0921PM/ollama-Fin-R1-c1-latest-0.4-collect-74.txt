- **Client**: Interacts with the system through various use cases like viewing dashboards, receiving alerts, and getting recommendations.

### Relationships:
1. Clients (`C1`) interact with most use cases directly (e.g., viewing dashboards).
2. System Administrator (`SA`) manages analysis parameters via `SAFR001`.
3. Financial Advisors (`FA`) manage client segments and mentoring sessions.
4. The system itself orchestrates all interactions, ensuring data flows between clients, advisors, AI components, and storage/logging.
