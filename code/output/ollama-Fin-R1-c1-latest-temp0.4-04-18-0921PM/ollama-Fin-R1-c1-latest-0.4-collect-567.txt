### Explanation:
- **Client**: Represents the end-users (clients) and their interactions. Each use case corresponds to a specific feature they need, like viewing dashboards or receiving alerts.
- **System Administrator**: Manages system-level parameters via `SAFR001`.
- **Financial Advisor**: A professional role with its own set of use cases for managing clients, detecting anomalies, generating reports, etc.
- **AI System**: The AI component that generates predictions, recommendations, and other insights. It's linked to the client through interaction points like requesting data or receiving alerts.
- **System** (as a package): Handles system-level operations such as delivering notifications, processing requests from clients/advisors, managing historical records, etc.

### Key Relationships:
1. **Client-to-AI**: Direct interactions for services (`C1 --> AIAgent`).
2. **Advisor-to-SysAdmin**: Advisors can configure analysis parameters via the SysAdmin role.
3. **AI-to-System**: AI components (e.g., `AIFR004`) request data or generate insights that are processed by system-level use cases like `SFR012`.
