1. **CFR001: View Financial Insights Dashboard** - Clients want to see their financial data in a consolidated dashboard.
2. **SAFR001: Manage Analysis Parameters** - SysAdmins adjust parameters for the AI system (e.g., risk thresholds).
3. **FAFR002: View Client Intervention Alerts** - Financial Advisors check alerts about clients needing attention.
4. **SFR013: Generate Client Alerts Based on Predefined Conditions** - The system proactively sends alerts to users based on set rules.
5. **AIFR006: Generate Anomaly Transaction Alerts** - AI detects unusual transactions and notifies the system.

- Clients use `CFR001` directly, while SysAdmins manage parameters through `SAFR001`.
- Financial Advisors can view specific alerts (`FAFR002`) or rely on generated ones via `AIFR006`.
