- **SysAdmin**: Represents System Administrators responsible for configuring analysis parameters within the AI system.
- **User**: A general term encompassing clients, financial advisors, or system administrators as defined in some requirements (e.g., FAFR002).
- **System**: The core functionality of the application, which includes generating alerts and recommendations via components like `AIFR006` for anomaly transaction detection.

**Key Use Cases:**
1. **CFR001 - View Financial Insights Dashboard**: Clients can access a consolidated view of their financial data.
2. **SAFR001 - Manage Analysis Parameters**: SysAdmins adjust parameters to ensure algorithm accuracy and compliance with regulations like Basel III.
3. **FAFR002 - View Client Intervention Alerts**: Users (including advisors) check alerts generated by the system for proactive client management.
4. **AIFR006 - Generate Anomaly Transaction Alerts**: The AI component detects unusual transactions based on historical data.
