Revised Quantitative Analysis Strategy for UML Diagram Comparison

This revised approach focuses entirely on automated metrics that can be computed without expert involvement, while still capturing the semantic and structural properties of the diagrams. The image-based analysis provides a complementary perspective to the code-based analysis, potentially identifying similarities and differences that might be missed in code-only analysis.



1. Element-Based Metrics (Automated)
1.1. Element Comparison

Actor Coverage Ratio: |Actors_generated ∩ Actors_reference| / |Actors_reference|
Use Case Coverage Ratio: |UseCases_generated ∩ UseCases_reference| / |UseCases_reference|
Relationship Coverage Ratio: |Relationships_generated ∩ Relationships_reference| / |Relationships_reference|
Missing Elements Count: Count of elements in reference but not in generated diagram
Superfluous Elements Count: Count of elements in generated but not in reference diagram

1.2. Element Property Automation

Name Similarity: Average Levenshtein ratio between matched element names
Type Correctness: Percentage of elements with correct types

2. Relationship Analysis (Automated)
2.1. Structural Analysis

Relationship Type Correctness: Percentage of relationships with correct types
Connection Correctness: Percentage of relationships connecting correct elements
Directional Correctness: Percentage of relationships with correct direction

2.2. Automated Semantic Analysis

Requirement Coverage: Percentage of functional requirements covered by use cases

3. Image-Based Similarity Metrics
3.1. Structural Similarity Index (SSIM)

Compute SSIM between rendered reference and generated diagrams
This captures overall structural similarity while being insensitive to minor pixel differences

3.2. Graph Edit Distance on Rendered Diagrams

Extract node and edge structures from rendered diagrams
Calculate normalized Graph Edit Distance between the extracted structures

3.3. Feature Matching

Extract SIFT or ORB features from both diagrams
Calculate feature matching percentage between diagrams

3.4. Component-wise Image Comparison

Segment images into components (actors, use cases, relationships)
Calculate similarity scores for each component type

4. Rework Effort Quantification (Automated)
4.1. Edit Operations Count

Element Addition: Count of elements to be added
Element Deletion: Count of elements to be removed
Element Modification: Count of elements requiring name/property changes
Relationship Addition: Count of relationships to be added
Relationship Deletion: Count of relationships to be removed
Relationship Modification: Count of relationships requiring changes

4.2. Weighted Edit Distance

Calculate weighted edit distance between PlantUML code files
Apply different weights to different types of edit operations

4.3. Overall Rework Score

Normalized score (0-100%) combining structural and semantic differences

6. Compelling Visualizations

Heat Map Visualizations:

Generate heat maps overlaid on the generated diagram highlighting areas requiring most rework
Color intensity represents magnitude of change needed


Difference Overlay Visualization:

Overlay reference and generated diagrams with color coding:

Green: Correct elements
Red: Missing elements
Yellow: Elements requiring modification
Blue: Superfluous elements




Radar Charts:

Multi-dimensional visualization showing performance across different metrics
Helps identify strengths and weaknesses of different LLM models


Sankey Diagrams:

Show flow from requirements to use cases and how well they're captured
Visualizes requirement traceability


Animated Transformation Visualization:

Create animation showing transformation from generated to reference diagram
Visually represents the rework process



7. Image-Based Semantic Analysis
For semantic image analysis without expert involvement:

Element Detection and Classification:

Train a model to detect and classify UML elements in rendered diagrams
Compare detection results between reference and generated diagrams


Graphical Network Structure Comparison:

Extract graphical network structure from diagram images
Compare topological properties of the networks


Text Recognition and Comparison:

Extract text from diagram images using OCR
Compare extracted text between diagrams
