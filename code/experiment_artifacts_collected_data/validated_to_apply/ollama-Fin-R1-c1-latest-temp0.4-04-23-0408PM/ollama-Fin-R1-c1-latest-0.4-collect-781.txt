- **Client**: Represents the user (including clients, advisors) who interacts with the system. They can view financial insights dashboards and receive alerts.
- **Financial Advisor (FAFD)**: A role specifically for advisors to manage mentoring sessions and access predictive analytics.
- **System Administrator (SysAdmin)**: Manages AI parameters like anomaly detection settings.

### Use Cases:
1. **CFR001**: View Financial Insights Dashboard – Client can view their financial data in a consolidated format.
2. **SAFR002**: Manage Anomaly Detection Parameters – SysAdmin adjusts thresholds for transaction alerts (e.g., fraud).
3. **FAFR005**: Schedule Mentoring Sessions – FAFD organizes client meetings based on system-generated insights.
4. **SFR013**: Generate Alerts Based on Conditions – System sends notifications when predefined conditions are met (e.g., spending limits, portfolio changes).
5. **AIFR007**: Correlate News with Portfolios – AI fetches relevant news for the user’s investment holdings.
