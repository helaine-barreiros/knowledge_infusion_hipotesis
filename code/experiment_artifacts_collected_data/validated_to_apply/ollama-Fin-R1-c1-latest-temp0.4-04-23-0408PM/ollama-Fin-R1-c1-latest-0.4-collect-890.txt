- **User** (general term for clients, advisors): Can access predictive analytics provided by the system through specific use cases like FAFR003: View Predictive Analytics for Clients.

4. **AIFR009 - Intervention Recommendations**: The AI generates recommendations when patterns requiring advisor attention are detected.
