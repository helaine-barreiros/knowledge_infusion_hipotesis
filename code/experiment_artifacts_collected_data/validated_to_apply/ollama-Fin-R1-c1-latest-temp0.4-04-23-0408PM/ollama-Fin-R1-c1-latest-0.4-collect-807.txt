- The system includes multiple actors such as **User**, **FinancialAdvisor**, and **SysAdmin**.
- Use cases are organized into categories based on their functionality. For example, client-related use cases like viewing dashboards or requesting recommendations fall under "Client" interactions, while administrative tasks (e.g., managing analysis parameters) are handled by SysAdmin.

1. **User Actor**: Represents clients (both individual and financial advisors). It has relationships with several system-use case pairs:
   - Viewing the Financial Insights Dashboard (`CFR001`).
   - Requesting financial predictions (`SFR003`), personalized recommendations (`SFR004`), spending limit alerts (`SFR005`), investment opportunity analysis (`SFR006`), and client dashboards (`SFR012`).

2. **FinancialAdvisor Actor**: Represents advisors who can view intervention alerts (`FAFR002`), predictive analytics for clients (`FAFR003`), or request specific AI-generated recommendations like predictive interventions (`AIFR008`).

3. **SysAdmin Actor**: Handles administrative tasks such as managing analysis parameters (`SAFR001`).

4. **Inheritance/Delegation**:
   - The `User` actor is extended by the `FinancialAdvisor`, meaning all client-related interactions (except those explicitly labeled for advisors) apply to both.
