- **AI Component**: AI-driven use cases (e.g., predictions, anomaly detection) are organized into their own component. The system requests these from the AI component via `SFR` use cases.

### Diagram Structure:
1. **Client** and **SysAdmin/Advisor** actors have distinct interfaces.
2. Use cases for each role are logically grouped under their respective packages (Professional, AdvisorTools).
3. System components (`System Core`, `AI Component`) handle internal logic but interact with external roles through defined use cases.

This structure ensures clarity in how different stakeholders engage with the system and its underlying AI capabilities. Each package is self-contained yet interlinked via relationships like requests from the client to the system, which then processes data using the AI component before delivering back to clients or advisors. The SysAdmin role provides administrative control over parameters affecting these interactions.
