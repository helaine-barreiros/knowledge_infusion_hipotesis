  - Financial Advisor uses use cases like `FAFR002`, `AIFR008`, and others.  

- **System Boundary**: The rectangle groups all system components (use cases) within the "system" boundary, ensuring clarity in relationships.

1. **User-to-Use Cases**  
   - Users interact with multiple use cases for viewing dashboards (`CFR001`), managing recommendations (`SAFR005`), and receiving alerts (`AIFR006`).  

2. **SysAdmin-to-Use Cases**:  
   - SysAdmin manages analysis parameters (`SAFR001`) and client preferences (`CFR005`).  

3. **FAdvisor-to-Use Cases**:  
   - Financial Advisors view intervention alerts, generate predictive insights, etc.  

4. **System Components (AIFR)**:
