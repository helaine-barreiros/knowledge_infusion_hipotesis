  The use cases are categorized into client-related (CFR), system administrator (SAFR), financial advisor (FAFR), and AI-generated services (AIFR).  

1. **Client Use Cases (CFR):**  
   - `View Financial Insights Dashboard` (`CFR001`).  
   - Receive alerts for anomalous transactions (`CFR002`).  
   - View financial predictions based on historical data and market trends (`CFR003`).  
   - Personalized recommendations aligned with their profile (`CFR004`).  
   - Manage preferences for personalized recommendations (`CFR005`).  
   - Spend limit alerts when exceeding thresholds (`CFR006`).  
   - View investment opportunities suitable to risk profiles (`CFR007`).  
   - Access consolidated financial dashboards (`CFR009`).  
   - Manage relationships with advisors, including data sharing permissions (`CFR10`).

2. **System Administrator Use Cases (SAFR):**  
   - `Manage Analysis Parameters` (`SAFR001`) to ensure compliance and accuracy.

3. **Financial Advisor Use Cases (FAFR):**  
   - Manage client mentoring sessions based on system insights (`FAFR001`).  
   - View intervention alerts for clients requiring attention (`FAFR002`).  
   - Analyze predictive analytics about clients’ financial situations (`FAFR003`).  
   - Configure analysis parameters by segment (`FAFR004`).

4. **System Use Cases (SFR):**  
   - Deliver personalized recommendations based on profiles (`SFR002`).  
   - Request financial predictions from AI (`SFR003`).  
   - Request spending limit alerts when thresholds are exceeded (`SFR005`).  
   - Analyze investment opportunities for users (`SFR006` and `SFR007`).  
   - Detect anomaly transactions via AML compliance (`SFR008`).  
   - Generate client dashboards (`SFR12`) and alerts (`SFR13`).  
   - Manage historical records of insights (`SFR19`).  

5. **AI Use Cases (AIFR):**  
   - Generate financial predictions by analyzing data (`AIFR001`), market trends, etc.  
   - Create personalized recommendations based on profiles and goals (`AIFR002`).  
   - Identify spending limit alerts for unusual patterns (`AIFR003`).  
   - Analyze investment opportunities matching risk profiles (`AIFR004`, `AIFR05`), including ESG factors.  
   - Detect anomaly transactions compliant with regulations (`AIFR06`).  
   - Correlate financial news to user portfolios (`AIFR07`).  
   - Recommend predictive interventions for advisors (`AIFR08`).  

- **Relationships:**  
  Clients can view dashboards, receive alerts, and manage recommendations. SysAdmin manages parameters. Financial Advisors use system-generated insights for client guidance. The `SFR` component handles requests from clients/system to generate various outputs (e.g., predictions, recommendations). AI components (`AIFR`) process data inputs into actionable intelligence.
