- **Client (User):** Can view the financial insights dashboard, receive alerts for anomalies, get personalized recommendations, manage preferences, and handle relationships with advisors.
- **System Administrator:** Manages analysis parameters, delivers recommendations to users via notifications, generates client-specific alerts based on conditions, and configures system-wide rules like spending limits or advisor interactions.
- **Financial Advisor (FAFR):** Views predictive analytics for clients, customizes analysis settings by segmenting clients into different groups (e.g., risk profiles).
- **AI System:** Generates financial predictions, personalized recommendations, spending limit alerts, investment opportunities, anomaly detection, contextualized news insights, and client-specific interventions.
