- **Client (User)**: Represents the end-users including clients who interact with various features like viewing dashboards, receiving recommendations, etc.
- **System Administrator**: Manages system-wide configurations such as analysis settings and alerts.

### Key Relationships:
1. **Client** directly requests services from use cases under "CFR" (e.g., viewing dashboards).
2. **SysAdmin** configures parameters for the AI system and client-specific alert preferences.
3. **Financial Advisor** uses specific features like predictive analytics or news insights tied to clients.
