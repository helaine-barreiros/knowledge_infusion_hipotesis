  - The system administrator (`SA`) manages AI-related parameters via SAFR001.

- **System Boundaries**:
  - `SysFunctionality`, an abstract boundary representing the core system components like recommendation engines, prediction requests, etc. It groups use cases such as delivering recommendations (SFR002), requesting financial predictions (SFR003), and others.
  
- **AI Component**: A nested rectangle housing AI-related functionalities like generating financial predictions (`AIFR001`), identifying spending alerts (`AIFR004`), analyzing investments against risk profiles (`AIFR005`).
  
- **Client Feedback**:
