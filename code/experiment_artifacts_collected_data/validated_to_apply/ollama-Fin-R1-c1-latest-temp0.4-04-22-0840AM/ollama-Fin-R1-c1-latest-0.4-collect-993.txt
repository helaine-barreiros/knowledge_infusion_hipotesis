- **Client**: Represents all users (Clients, Financial Advisors, and System Administrators) who interact with the system. The Client can view financial dashboards (`CFR001`) or manage anomaly detection parameters via a SysAdmin.
- **System Administrator**: Manages analysis parameters for AI components like `SAFR002` to ensure compliance and accuracy.
- **Financial Advisor (FAAdvisors)**: Can schedule mentoring sessions, review client intervention alerts (`FAFR003`), view predictive analytics about clients’ financial situations (`AIFR008`).
  
### Use Cases:
1. **CFR001**: View Financial Insights Dashboard – Client can access a consolidated dashboard.
2. **SAFR001**: Manage Analysis Parameters – SysAdmin adjusts AI parameters for accuracy and compliance (e.g., Basel III, FATF regulations).
3. **FAFR001**: Schedule Mentoring Sessions – FAAdvisors plan client interactions based on system-generated insights.
4. **AIFR007**: Generate Contextualized News Insights – System requests relevant news articles tied to user portfolios.

### Relationships:
