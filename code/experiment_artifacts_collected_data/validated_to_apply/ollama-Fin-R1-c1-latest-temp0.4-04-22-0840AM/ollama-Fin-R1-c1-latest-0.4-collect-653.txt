- **System Administrator Interface**: System Admins manage AI parameters via `SAFR001`.
- **Financial Advisor Interface**: Advisors handle mentoring sessions (`FAFR001`), view client alerts/predictions (`FAFR002`, `FAFR003`), and configure segment-specific analysis settings (`FAFR004`).
- **System Component**: The main system handles all requests from clients, advisors, and the AI. It includes sub-systems like delivering alerts (`SFR001`), generating recommendations (`SFR002`), requesting data from AI components (e.g., `SFR003`, `AIFR001`).
- **AI Component**: Generates predictions, personalized recommendations, spending limit alerts, etc. (`AIFR001–AIFR008`).
- **Feedback Loop**: Clients can provide feedback to improve system accuracy and relevance.
