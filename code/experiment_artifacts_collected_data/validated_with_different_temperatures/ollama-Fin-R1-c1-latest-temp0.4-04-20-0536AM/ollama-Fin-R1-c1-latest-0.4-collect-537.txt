2. **SysAdmin** manages parameters related to AI compliance (e.g., Basel III).
3. **FinancialAdvisor** receives personalized recommendations from the system for clients.
4. The system itself requests data or analyses from its components like AIFR001.

### Diagram Structure:
- Use cases are organized under a "System" boundary, which represents all internal processes and interactions within the application.
- Actors (Client, SysAdmin, FinancialAdvisor) are defined outside this boundary but connect to specific use cases inside it.
