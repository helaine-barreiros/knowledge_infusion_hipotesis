**Description:**
This PlantUML diagram represents the use case interactions within an AI-powered analysis and insights system. The main actors are **Client**, **FinancialAdvisor**, and **SysAdmin**, each interacting with various use cases defined by their functional requirements.

### Key Components:
1. **System Boundary**: Encloses all use cases, ensuring they operate as a cohesive unit.
2. **Use Cases**:
   - **Client-Related Use Cases (CFR)**: View dashboards, receive recommendations, manage preferences, etc.
   - **FinancialAdvisor-Related Use Cases (FAFR)**: Schedule mentoring sessions, view client alerts/predictions.

### Relationships:
- **Client** interacts with most use cases directly except those managed by SysAdmin or FinancialAdvisor.
- **FinancialAdvisor** handles client mentoring sessions and alerts/predictive analytics.
- **SysAdmin** manages system parameters (e.g., SAFR001).
- Use cases like SFR002, AIFR002 are linked to generate recommendations based on user interactions.

- Some use cases extend others logically. For example, `SFR009: Extract Contextualized News` is a sub-use case under the broader system function of delivering news insights (`SFR001`).
