1. **Actors**:
   - `Client`: Represents the end-users (financial clients).
   - `SysAdmin`: System Administrator responsible for managing system parameters.
   - `FAFrAdvisor` (Financial Advisor): Financial professionals using the system.

2. **Use Cases**:
   - **CFR001: View Financial Insights Dashboard**: Client wants to see their financial data in a consolidated view.
   - **SAFR001: Manage Analysis Parameters**: SysAdmin adjusts AI parameters for accuracy and compliance.
   - **FAFR004: Configure Analysis Parameters for Client Segments**: FAFrAdvisor customizes system settings based on client profiles (e.g., risk tolerance, goals).
   - **SFR002: Deliver Personalized Recommendations Based on Profiles**: System provides tailored financial advice to clients and advisors.
   - **AIFR002: Generate Personalized Recommendations from AI System**: AI component creates recommendations using user data.

3. **Relationships**:
   - Clients use the dashboard (CFR001).
   - SysAdmin manages parameters (SAFR001).
   - Advisors configure segment-specific settings (FAFR004) and receive recommendations via SFR002.
   - The AI system generates recommendations through AIFR002, which are delivered to clients/advisors.
