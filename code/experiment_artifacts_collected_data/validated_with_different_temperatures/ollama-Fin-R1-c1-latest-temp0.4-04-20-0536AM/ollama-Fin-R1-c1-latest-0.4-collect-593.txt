- **System Boundary**: The main rectangle represents the "System" which includes all use cases and actors related to client interactions, administrative tasks, financial advisor activities, and the underlying AI components.  
- **Client Interactions** (CFR001): Clients can view a financial insights dashboard through direct interaction with the system (`client --> CFR001`).  
- **System Administrator**: Manages analysis parameters via `SAFR001`.  
- **Financial Advisors**: Can manage client mentoring sessions and view predictive analytics about clients’ financial situations. They also receive alerts from the system (e.g., FAFR002).

- **Feedback Loop**: Users can provide feedback on recommendations and insights (e.g., CFR011), which helps the system improve over time.
