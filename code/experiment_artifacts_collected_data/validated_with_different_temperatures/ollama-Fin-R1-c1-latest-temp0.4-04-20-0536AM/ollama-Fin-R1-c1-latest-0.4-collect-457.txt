   - **CFR001: View Financial Insights Dashboard** (Client): Allows clients to view their financial data in an organized dashboard.
   - **SAFR001: Manage Analysis Parameters** (SysAdmin): System administrators can adjust parameters for AI algorithms.
   - **FAFR002: View Client Intervention Alerts** (User/FinancialAdvisor/SystemAdministrator): Users, advisors, or admins receive alerts about client issues needing attention.
   - **SFR013: Generate Client Alerts Based on Predefined Conditions** (System): The system automatically generates alerts based on set rules.
   - **CFR006: Manage Spending Limit Thresholds** (Client): Clients can adjust their spending limits in specific categories.
   - **AIFR005: Identify Investment Opportunities Aligning with Risk Profiles** (AI System/FinancialAdvisor): AI suggests investments matching user risk profiles and goals.
   - **SFR008: Request Anomaly Transaction Alerts from AI Component** (System): The system requests alerts for potential fraud based on user spending patterns.

   - **User**: A general term encompassing both Clients and Advisors for clarity.
